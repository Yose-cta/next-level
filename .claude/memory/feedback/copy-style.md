## ❌ NUNCA usar (voseo argentino)

- vos / tenés / querés / podés / sabés / sos / venís
- decime / pasame / contame / mirá / andá / dale
- "che" / "bueno dale" / "ya" (en sentido argentino)

## ✅ SIEMPRE usar (español neutro/chileno)

- tú / tienes / quieres / puedes / sabes / eres / vienes
- dime / pásame / cuéntame / mira / ve / vamos
- "ok" / "bien" / "perfecto" / "claro"

## Ejemplos de transformación

| ❌ Argentino | ✅ Neutro/chileno |
|---|---|
| "Andá a la URL" | "Ve a la URL" |
| "Decime cuando termines" | "Avísame cuando termines" |
| "¿Querés que verifique?" | "¿Quieres que verifique?" |
| "Pegame el link" | "Pásame el link" |
| "Vení con preguntas" | "Ven con preguntas" |
| "Vas a recibir" | "Vas a recibir" (esta SÍ se mantiene) |
| "Pasame los datos" | "Pásame los datos" |
| "¿Cuál preferís?" | "¿Cuál prefieres?" |
