⏳ Recupera tiempo 30 minutos para tener todo funcionando Gratis · ~$3 USD/mes en uso

Tu propio asistente de WhatsApp respondiendo 24/7.

Un agente con IA que atiende a tus clientes en WhatsApp, responde sus dudas, agenda citas y filtra preguntas — mientras tú duermes, comes con tu familia, o estás dando una clase. Lo armas en 30 minutos respondiendo 10 preguntas sobre tu negocio.

¿Qué construye?

Un agente de WhatsApp completo: recibe mensajes, los entiende con IA, busca información de tu negocio (menús, horarios, precios) y responde en segundos. Aprende del historial de cada cliente.

¿Para quién es?

Restaurantes (especiales del día), clínicas y salones (citas), inmobiliarias (filtro de propiedades), coaches y consultoras (calificación de leads), tiendas (consultas de pedido).

Resultado validado

24/7

Reduce tiempo de respuesta de horas a segundos. Filtra hasta el 80% de mensajes repetidos antes de que lleguen a ti.

Lo que necesitas tener antes de empezar

No te preocupes si no entiendes algún término — abajo te explico paso a paso cómo conseguir cada cosa.

1
Python instalado
Mac: brew install python. Windows: descarga gratis desde python.org. Es el motor donde corre el agente.
2
Claude Code (gratis)
La herramienta de Anthropic que va a escribir todo el código por ti. Más adelante te muestro cómo instalarla con un comando.
3
API Key de Anthropic
La sacas en platform.anthropic.com. Es como una contraseña que conecta tu agente con la IA. Cobra ~$3 por millón de palabras procesadas.
4
Cuenta WhatsApp Business API
Para empezar gratis usa Whapi.cloud (sandbox). Para producción usa Meta Cloud API. El agente te conecta automáticamente.

El paso a paso

Solo 3 comandos para instalar y luego una conversación con Claude. Sigue el orden.

1
Descarga el proyecto a tu computadora
2 minutos

Abre tu Terminal (Mac) o PowerShell (Windows). Pega este comando exacto y presiona Enter. Va a crear una carpeta nueva con el código del agente.

Comando 1 · Copiar y pegar
git clone https://github.com/Hainrixz/whatsapp-agentkit.git cd whatsapp-agentkit
¿Qué hace? Trae el código desde GitHub a tu compu y entra a la carpeta. No corre nada todavía.
2
Instala Claude Code y arranca el script
3 minutos

Si es la primera vez que usas Claude Code, instálalo con npm. Después corre el script de arranque.

Comando 2 · Instalar Claude Code (solo primera vez)
npm install -g @anthropic-ai/claude-code
Comando 3 · Arrancar el setup
bash start.sh
¿Qué hace? Instala Claude en tu sistema y verifica que tienes todo listo. Te avisa si falta algo.
3
Habla con Claude para que arme tu agente
5 minutos

Abre Claude Code dentro de la carpeta y dile que construya tu agente. Te va a hacer 10 preguntas sobre tu negocio.

Comando · Abrir Claude
claude
Una vez dentro, escribe
/build-agent
Las 10 preguntas: nombre del negocio, sector, propósito del agente, nombre del agente, tono, horario, archivos (menú/precios/FAQ), tu API Key Anthropic, proveedor WhatsApp, credenciales del proveedor.
4
Prueba localmente que funciona
5 minutos

Antes de conectarlo a WhatsApp real, ábrelo en tu terminal y conversa con él. Asegúrate que entiende tu negocio.

Comando · Conversar en terminal
python tests/test_local.py
Qué hacer: hazle preguntas reales que un cliente te haría. Si responde mal, vuelves a Claude y le dices: "Haz que el agente sea más amigable".
5
Subirlo a producción 24/7
10 minutos

Recomendado: Railway (fácil, gratis para empezar).

Pasos · Railway
1. Sube tu carpeta a GitHub 2. Entra a railway.app 3. Conecta el repositorio 4. Pega tus API Keys en Variables 5. Listo — Railway despliega automáticamente
Después del deploy: conectas el webhook que te da Railway con tu proveedor de WhatsApp y los mensajes empiezan a fluir solos. El agente ya está vivo 24/7.
Casos reales
  • Restaurante: especiales del día y horarios sin estar pegado al celu
  • Clínica/Salón: agenda citas y manda recordatorios automáticos
  • Inmobiliaria: filtra propiedades por presupuesto antes del ejecutivo
  • Coach: califica leads (presupuesto, urgencia) antes de la llamada de venta
  • Tienda: consultas de estado de pedido sin saturar al equipo
Errores que evitar
  • No subas tu API Key a GitHub público (créala como variable de entorno)
  • Empieza con Whapi.cloud sandbox, no con WhatsApp real
  • Si inventa información, dile a Claude: "Cuando no sepas, di que no tienes la información"
  • Para múltiples negocios clona el repo en carpetas separadas
  • Revisa el costo en platform.anthropic.com cada semana al inicio

Si llegaste hasta aquí leyendo y aún no te animas, en mi mentoría 1:1 lo dejamos funcionando en una sesión. Trae tu negocio, salimos con el agente vivo.

  • Qué NO debe aparecer
  • Ejemplos previos como referencia
  • Métrica de éxito (cómo validar que funcionó)

Errores que evitar
  • Prompts sin contexto = outputs genéricos
  • Saltarte el Master Prompt = perder primer intento
  • Empezar con las 6 a la vez — abruma
  • Mezclar herramientas sin rol claro
  • Stack pensado para 8+ reels/mes, no 1

Los 3 agentes que vas a tener

🤖 Recepcionista WhatsApp 24/7

Recibe mensajes, detecta intención (agendar, info, queja). Consulta tu Google Calendar. Resumen diario por correo.

📧 Ordenador de Gmail

Revisa correos cada 15 min. Clasifica: clientes prioritarios, presupuestos, newsletters. Mueve a carpetas según contenido.

📞 Recepcionista de llamadas

Vía Twilio contesta con saludo personalizado. Agenda citas o da info. Escala urgencias a tu celu. Resume en Slack.

2
Conecta a Claude
2 minutos
Config Claude Code
{ "mcpServers": { "n8n-mcp": { "command": "npx", "args": ["n8n-mcp"], "env": { "MCP_API_KEY": "tu-api-key" } } } }
3
Verifica conexión
1 minuto
Health check
Usa la herramienta n8n_health_check del MCP de n8n-mcp y dime si la conexión está viva, versión, workflows activos/inactivos, errores de credenciales.
4
Pídele tu primer agente
15-30 minutos
Recepcionista WhatsApp
Arma un workflow en n8n para recepcionista WhatsApp 24/7 para mi consultoría: - Recibe mensaje - Detecta intención (info, agendar, otro) - Si quiere agendar: consulta Google Calendar y propone 3 horarios - Si quiere info: responde según mi documento de servicios - Si es otra cosa: me reenvía a mi WhatsApp - Cada noche resumen al correo

  • Backup periódico — el MCP no respalda. Snapshots de BD aparte
